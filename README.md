## About

NoInUPI is an Android project exploring offline UPI payments through USSD banking infrastructure.

The idea is simple: make payments without depending on a conventional internet connection.

## Features

- USSD-based banking interaction
- Minimal Android interface
- Local transaction history
- Payment status screens
- Designed for situations with limited or no internet access

*Feature availability depends on the current implementation and supported banking services.*

## Tech Stack

- Kotlin
- Jetpack Compose
- Android SDK
- USSD banking infrastructure

## Requirements

- An Android device
- An active SIM card
- A bank account with supported USSD banking services
- Cellular network availability

## Limitations

- USSD availability depends on your mobile carrier and network conditions.
- Supported banking features vary by bank.
- Transactions require confirmation from the banking system.
- Offline internet access does not mean offline cellular connectivity.

## Disclaimer
